# 防爆空调电商运营分析平台 — 需求文档

> **版本**：V1.0
> **日期**：2026-04-20
> **业务方**：防爆空调/电器电商运营&财务团队

---

## 1. 项目背景与目标

### 1.1 业务背景

公司是主营**防爆空调、防爆电动工具**等工业防爆电器的电商企业，在**天猫**和**京东**（五金类目）两大平台开店销售。

目前每月财务核算流程存在大量手工操作：
- 从各平台后台手动导出销售、退款、资金账单、推广费等 CSV/Excel 文件
- 使用 Excel 数据透视表手工分类整理费用
- 人工匹配订单号进行收入与成本的核销
- 刷单订单需要手工标记和剔除
- 跨平台数据汇总靠人工拼接，容易出错

### 1.2 项目目标

建设一套**运营分析平台**，实现：
1. **统一数据入口**：天猫、京东导出的原始账单文件一键导入，自动解析
2. **自动化核算**：销售收入、成本、退款、回款自动计算和匹配
3. **多维度报表**：按店铺、商品、月份等维度自动生成经营报表
4. **利润核算**：自动计算月度毛利润、净利润，支持刷单剔除
5. **可视化看板**：关键经营指标一目了然

## 3. 功能需求

### 3.1 数据导入管理

#### 3.1.1 文件上传

| 需求项 | 说明 |
|--------|------|
| 支持格式 | CSV（GBK编码）、Excel（xlsx） |
| 支持平台 | 天猫、京东 |
| 支持类型 | 发货数据、销售账单、资金账单、售后退款、推广费 |
| 文件校验 | 上传时自动校验字段完整性、编码、数据量异常提醒 |
| 重复检测 | 同一账期同一类型文件重复上传时提示覆盖或跳过 |
| 批量上传 | 支持一次上传多个文件 |

#### 3.1.2 数据解析规则

**天猫数据解析**：
- 自动识别 Tab 分隔、GBK 编码
- 账期字段作为数据月份标识
- 账单大类 = "货款收入" 的记录归入销售收入
- 退款单号非空的记录标记为退款订单

**京东数据解析**：
- 自动识别逗号分隔、GBK 编码
- 按"费用项"字段拆分：货款 → 销售收入；佣金/保险服务费/交易服务费 → 费用支出
- 按"收支方向"字段判断收入/支出
- 单据类型 = "非销售单" 的记录标记为非交易类费用

#### 3.1.3 数据标准化

所有导入数据统一转换为平台标准数据模型：

| 标准字段 | 天猫映射 | 京东映射 |
|----------|----------|----------|
| 平台 | 天猫 | 京东 |
| 订单号 | 订单号 | 订单编号 |
| 商品名称 | 商品名称 | 商品名称 |
| SKU | sku | （从商品名称提取） |
| 商品ID | 商品ID | 商品编号 |
| 数量 | 数量 | 商品数量 |

| 下单时间 | 下单时间 | 费用发生时间 |
| 发货时间 | 确认收货时间 | 费用结算时间 |
| 费用类型 | 账单大类+业务小类 | 费用项 |
| 收支方向 | 根据金额正负判断 | 收支方向 |

### 3.2 销售收入核算

#### 3.2.1 销售收入计算

**规则**：
1. 从"销售主体分析报表"（天猫/京东导入数据）中提取当月发货收入
2. 以**发货时间/确认收货时间**为准统计当月数据
3. 实销金额 = 销售收入 - 刷单金额
4. 刷单订单通过关联"刷单标识表"自动匹配剔除

**输出指标**：
- 当月发货收入总额（分平台）
- 刷单金额（分平台）
- 实销金额（分平台）
- 按商品/类目/店铺维度拆分
- 环比/同比增长率

#### 3.2.2 成本核算

**规则**：
1. 从发货数据中提取当月出库成本
2. 出库成本 = 商品数量 × 商品成本单价
3. 刷单成本需要减去：实销成本 = 出库成本 - 刷单成本
4. 商品成本单价来自"商品成本表"维护

**输出指标**：
- 当月出库成本总额
- 刷单成本金额
- 实销成本
- 毛利率 = (实销金额 - 实销成本) / 实销金额 × 100%

#### 3.2.3 售后退款核算

**退款金额核算**：
1. 从售后主体分析报表筛选"退款成功"记录
2. 与实际销售收入按订单号匹配
3. 核算退款差异 = 申请退款金额 - 实际退款金额
4. 按退款原因分类统计

**退款成本核算**：
1. 统计实际退款后入仓库成本
2. 退款入库成本 = 退款商品数量 × 商品成本单价
3. 区分"可二次销售"与"不可二次销售"（报废）

**输出指标**：
- 退款订单数 / 退款金额
- 退款率 = 退款金额 / 销售收入 × 100%
- 退款差异总额
- 退款入库成本
- 退款报废成本
- 按商品/退款原因分类统计

#### 3.2.4 回款核算

**规则**：
1. 匹配资金账单中的打款记录
2. 按订单号/商户订单号关联销售收入
3. 核算当月实际回款金额
4. 对比"应回款"与"实际回款"，计算回款差异

**输出指标**：
- 当月应回款总额
- 当月实际回款总额
- 回款差异（未回款/多回款）
- 回款周期分析（发货至回款天数）
- 按平台/账期汇总

#### 3.2.5 店铺销售费用

**费用分类规则**：
将平台资金账单中的费用项自动分类：

| 费用大类 | 包含费用项 |
|----------|-----------|
| 平台佣金 | 佣金、交易服务费 |
| 保险费用 | 商品保险服务费、运费保险服务费 |
| 推广费用 | 直通车、京东快车、钻展等推广费 |
| 物流费用 | 运费、仓储费 |
| 违约金 | 综合违约金、延迟发货赔付 |
| 其他费用 | 随单送的京豆、技术服务费等 |

**核算方式**：
1. 按费用大类汇总当月总费用
2. 按商品/订单分摊费用（可选）
3. 费用率 = 总费用 / 销售收入 × 100%

### 8.3 待确认事项

以下事项需要与业务方进一步确认：

1. **发货数据 Excel 字段确认**：需要确认 `ExportOrderList26368632003.xlsx` 的具体字段，以便设计成本核算逻辑
2. **推广费数据格式**：目前暂无推广费样本数据，需确认天猫直通车、京东快车等导出的文件格式
3. **刷单标识方式**：刷单订单是通过订单号手动维护，还是有其他标记方式？
4. **商品成本来源**：商品成本单价是固定值还是动态变化？是否需要成本变动历史？
5. **多店铺支持**：目前是否只有一个天猫店和一个京东店？未来是否会扩展更多店铺？
6. **数据权限**：不同角色（运营、财务、老板）需要看到的数据范围是否不同？
7. **历史数据**：是否需要导入历史月份数据？数据量大约多少？
8. **部署环境**：系统部署在内网服务器还是云服务器？
